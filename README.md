# FURIER-
TRANSFORMADA DE FURIER 
El programa desarrollado en MATLAB tiene como objetivo generar y analizar tres señales básicas: un pulso rectangular, una función escalón y una señal senoidal. Primero se definen parámetros generales como la frecuencia de muestreo, el número de muestras y el vector de tiempo, lo que permite trabajar con señales digitales.

Después, se crea cada señal en el dominio del tiempo y se grafica para observar su comportamiento. Posteriormente, se aplica la función fft() para obtener la Transformada de Fourier de cada señal, lo que permite convertirla al dominio de la frecuencia.

Finalmente, el programa grafica la magnitud y la fase del espectro de cada señal, permitiendo comparar cómo cambia su representación al analizarla en términos de frecuencias. De esta manera, se demuestra la utilidad de la Transformada de Fourier en el análisis y procesamiento digital de señales.
